## Ownership invariants for the test

| Resource | Creates it | Owner / allowed access | Closes it | Terminal behavior covered |
|---|---|---|---|---|
| Shared in-memory network fabric | One test case | Test case; only the real `InMemoryNetworkProvider` instances use it | Test case, after all nodes close | Closed after client, facades, and nurseries stop |
| Two in-memory network providers and their URL resolvers | Test case | Each `UrlFacadeProvider` owns its injected server resolver; test owns the client resolver | Facades close server resolvers; test closes client resolver | Closed resolvers are not reused |
| Two ContainerNursery instances and their backend containers | Test case / each `ContainerProvider` | Each nursery owns its created container; test retains handles only for cleanup and observation | Nursery shutdown, then explicit idempotent backend cleanup | Shutdown closes TCP bindings and stops handlers |
| Client RPC streams | Client resolver through public `openPersistentRpcConnection` | Each returned persistent connection owns its stream; test may close the captured target stream only in the accepted-effect case | Test closes all persistent connections | A closed target stream cannot replay an accepted request |
| Frame fault state | Test case decorator around the client's real `NetworkProvider.dial` result | Test controls only the selected target method; normal bytes pass through to the real stream | Test releases gates in `finally` | One-shot refusal, partial write, and accepted-request close each terminate after their controlled event |
