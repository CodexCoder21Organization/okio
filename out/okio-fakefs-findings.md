Invariant table before code:
| Resource | Creator/owner/close | Caller-visible behavior and difficult cases |
|---|---|---|
| Stored file bytes | File element / filesystem; retained after handle close | append linear; overwrite preserves suffix; gap bytes are zero; resize shrink/regrow zeroes retired bytes |
| File handle | openReadWrite/openReadOnly / caller / use/close | data remains after reopen; closed operations fail; registry removed on close |
| Replacement writable open | open / new File element / caller | original open handles keep their own content view; new writes cannot mutate the prior view |
| Input/output arrays | caller / caller | writes copy caller data; reads cannot expose stored mutable arrays; source offsets and destination guards respected |
| Read cursor | one read / one operation / use | bulk segment copies preserve existing read workload; EOF at Long offsets checked without narrowing |
INFER: Store Buffer directly, copy it on replacement writable open, and use scoped cursors for bulk reads and in-place overwrite; append directly. This avoids snapshot allocation while retaining copy-on-write isolation between elements. Existing FakeFileSystem is documented as not thread safe; no new concurrent contract is introduced.
