| Resource | Creator/owner/close | Caller-visible behavior and difficult cases |
|---|---|---|
| Stored file bytes | File element / filesystem; retained after handle close | append linear; overwrite preserves suffix; gap bytes are zero; resize shrink/regrow zeroes retired bytes |
| File handle | openReadWrite/openReadOnly / caller / use/close | data remains after reopen; closed operations fail; registry removed on close |
| Replacement writable open | open / new File element / caller | original open handles keep their own content view; new writes cannot mutate the prior view |
